# SafeNet-ZKP
SafeNet-ZKP: Gateway de Acesso Preservador de Privacidade para redes Wi-Fi públicas. Substitui cadastros por autenticação sem senha (WebAuthn/FIDO2) e validação anônima via Provas de Conhecimento Zero (ZKP). Desenvolvido em C# (.NET) e Angular para o TCC em Redes de Computadores no IFCE.
